Current version: Prototype 0.11a, 12 classes (adds Thief, Priest, Woodcutter, Firemaker, Necromancer, Slayer, Hunter, Runecrafter), all open with no unlock requirements on the main link.
Test build: Prototype 0.11a (12 classes) at https://hatchetnlette.github.io/Last-Stand/test/
0.11b (test link): retro synthesized sound effects with a Sound toggle and volume slider.
