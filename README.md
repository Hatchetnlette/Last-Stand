# Last Stand

A RuneScape-flavored horde-survivor mobile web game.

Current version: Prototype 0.10a: a 5-slot in-run bag, RuneScape items from timed and royal chests (armour, jewellery, capes, food, potions, uniques, Dharok set), and a bag-full swap/leave sheet.
Test build: Prototype 0.11a (12 classes) at https://hatchetnlette.github.io/Last-Stand/test/
